# Capsule / Rig Lab — интерактивная демка на Three.js

Веб-сцена для позинга **того же капсульного персонажа**. Модель экспортирована из `capsule_mannequin.blend`: **85 костей**, веса скиннинга и пять материалов. Не картинка и не фальшивый манекен из браузерных примитивов.

## Запуск исходников

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Сервер нужен для загрузки 3D-файла; просто двойной клик по `index.html` не работает из-за браузерных ограничений `file://`.

Если в архиве есть папка `site/`, это уже собранная статическая версия. Её можно запустить **без npm**:

```bash
python -m http.server 8000 --directory site
```

После этого откройте `http://localhost:8000`. Никаких внешних CDN или API приложение не вызывает.

## Управление

- **Кликните по сегменту модели или по точке сустава**, чтобы выбрать исходную кость; слева также доступен список всех 85 костей и поиск.
- **Тяните цветные кольца вокруг сустава** для вращения кости в 3D. Переключатель «Локальная / Мировая» меняет ориентацию манипулятора. Удерживайте **Shift** для шага 15°.
- **Углы X/Y/Z** справа задают точное вращение относительно исходной позы кости. Можно менять ползунками или вводить число.
- Мышь на пустом месте вращает камеру; колесо приближает/отдаляет. «3/4», «ФАС» и «БОК» выбирают ракурс. Включаются маркеры суставов, линии скелета и сетка.
- Четыре позы: **Т-поза, Спокойно, Привет, Шаг**. Демка открывается в спокойной позе, а кнопка «Т-поза» возвращает оригинальный rest pose модели.
- Кнопки **Скачать JSON / Загрузить позу** переносят вращения всех костей между сеансами. Приложение также сохраняет изменения в `localStorage` браузера.
- Клавиши: **/** поиск; **F** общий вид; **R** сброс выбранной кости; **Esc** снять выбор.

Это *FK-позинг* (вращение костей), а не IK-перетаскивание кисти в произвольную точку и не физическая симуляция. Веса сегментов жёсткие, поэтому экстремальные углы могут открыть зазор в суставе — как у исходного сегментированного дизайна.

## Файлы и экспорт модели

- `public/model/capsule_character.glb` — автономная WebGL-модель: 85 исходных костей, скиннинг и 5 материалов. Исходные `Body`/`Head`, свет и пол из `.blend` в него **не** включены.
- `src/main.js` — Three.js сцена, GLTFLoader, OrbitControls, TransformControls, позы, выбор кости по скиннингу, JSON.
- `src/style.css` и `index.html` — адаптивный интерфейс на русском.
- `tools/export_glb.py` — повторный экспорт GLB из `.blend` без изменения самого Blender-файла. Из корня проекта:

```bash
blender -b /путь/к/capsule_mannequin.blend --python tools/export_glb.py -- --output public/model/capsule_character.glb
```

- `npm run build` создаёт статическую папку `dist/`; `npm run preview` проверяет её локально. Для Playwright-проверки интерфейса: `npx playwright install chromium`, запустить `npm run dev`, затем `node tools/smoke_test.mjs`.

**Важно:** Three.js при импорте приводит некоторые имена костей к безопасному виду (`upper_arm.L` → `upper_armL`). Интерфейс восстанавливает настоящие имена из узлов GLB и сохраняет в JSON именно исходные имена FBX. Масштаб в веб-сцене подогнан до ~2,22 единицы высоты **только для просмотра**; сохранённый Blender/FBX остаётся исходного размера.
